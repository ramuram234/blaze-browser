# Blaze

A UC Browser–style mobile web browser: orange chrome, turbo pages, tabs, news, videos, and a gesture media player.

## Features

- Home screen with search, shortcuts, weather, and news
- Turbo reader mode plus full-site fallback
- Tabs, private tabs, bookmarks, history, downloads
- Night mode, voice search, ad-block toggle
- Videos hub with a swipe player:
  - Swipe left / right to seek
  - Right edge up / down for volume
  - Left edge up / down for brightness
  - Preloads the next clip for faster playback
- Opens YouTube links and page videos in the player

## Run locally

```bash
npm install
npm run dev
```

Then open the printed local URL. The UI is built for a phone screen.

```bash
npm run typecheck
npm run build
```

## Stack

TanStack Start, React, Tailwind CSS, Zustand.
